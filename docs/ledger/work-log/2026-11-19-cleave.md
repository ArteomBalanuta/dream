# Work log: Cleave as a timed swing

- Purpose: record Cleave becoming a timed swing with a shared timeline, a delayed server hit, a clip, a timed
  slash effect and a quickbar icon.
- Status: done, on branch `cleave/int` from `a7d7eff5`.
- Plan: `docs/ledger/plans/2026-11-19-cleave.md`.

## What landed

- **Combat.** Cleave costs 5 mana and has no target cap (`SkillDefinition.AllTargets`, the MeleeArc default when
  `maxTargets` is omitted). An accepted cast queues a pending swing in `WorldSessionRuntime.MeleeSwings.cs`,
  advanced each simulated tick before respawns; it sweeps the cone every tick of the active window and hits each
  target once through `AuthoritativeCombatResolver.ResolveMeleeArcSweep`. The result now reports 0 hits at cast
  time; the integration tests read hits after the window instead.
- **Animation.** `clip_cleave` in `tools/ui-assets/gen_char_player.py`: a lunge with the torso coiled to the
  caster's left during the wind-up, a whip through the active window (hips, then torso, then arm), and an ease back
  to rest. `check_char.py` gates left -> forward -> right on the weapon tip, with a mirrored-clip negative. The
  state machine plays it on a new `SkillSwingSerial`; `ClientScenePresenter` counts remote MeleeArc cast events and
  `PlayScene` counts the local player's accepted MeleeArc casts.
- **Effect.** The arc atlas cell is repainted to `FxArcGeometry`. `FxSimulation` queues arc casts in a fixed
  8-slot array and emits the crescent and sweeping sparks only once the wind-up ends.
- **Icon.** `skill.cleave` in the items atlas: a dark steel blade with a pale crescent trail.

## Findings worth keeping

- Model space: the player faces +Z and +X is the caster's left (`arm-right` sits at x = -0.7).
- The particle atlas is uploaded unflipped and the shader flips V, so local +Y is the top of the cell image; with
  the arc rotation that maps to the caster's right. The bright tip is at image y < 0.
- `OuterRadiusFraction` is 24/32, not the hoped-for 30/32: a cell draws 28 px and its outer 3 px must stay dark for
  `check_particles.py`, so 24 px is the largest edge that passes.
- Adding the icon grew the items atlas by 6 px and moved one other rect (`fx.aura.blob`), because the shelf packer
  sorts by height then name. Loaders read rects from `items.json`, so nothing else changed.
- `check_sources.py` still reports the two pre-existing problems in `enginelook.py`; any third is new.
