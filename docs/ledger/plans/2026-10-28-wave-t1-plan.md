# Wave T1 Plan: Clock, Shared Lighting, Sky

Purpose: split wave T1 of the day/night roadmap (`2026-10-28-day-night-roadmap.md`) into five workstreams that can run in parallel.

Status: the C0 contract files are committed on `integrate/engine-iteration`. All five branches start from that commit. The architect wrote this plan.

## Key facts from the code

- **Server tick and world ticks.** `ServerTickRunner` numbers ticks consecutively. `WorldSessionRuntime.AdvanceAuthoritativeTick` sets `CurrentServerTick` (`WorldSessionRuntime.Tick.cs`). So `WorldTicks - CurrentServerTick` is constant for the whole process, and an anchor is just an offset.
- **Join message.** `JoinAcceptedMessage` is serialized by reflection: camelCase, with nulls omitted. The world-transfer split and reassembly use `with` (`WorldTransfer.cs`), so a new trailing parameter survives a chunked join. The message is built only in `RuntimeAuthoritativeSessionHost.JoinSession`, at two sites.
- **Client tick.** The client tracks the server tick in `PlayScene._serverTickClock`. `RemotePlayerRenderTick` (its `RenderTick`) is a monotonic `double`.
- **GL version.** The context is GL 3.3 core (`#version 330`), which has no `layout(binding=N)` on a block. Bind with `GL.UniformBlockBinding` after the program links.
- **Today's lighting:**
  - The `cube` program draws terrain, cubes, models and view models. It uses a point light at (4,2,2) with ambient 0.2.
  - The `enemy` program draws wolves and players. It uses a point light at (4,4,2), ambient 0.65, diffuse ×0.75, and a floor of 0.35×base.
  - The view model uses the `cube` program with view = identity, so its `fragPos` is in eye space.
  - The far plane is 100. `WorldVisibility.MaxRenderDistance` is 48.
- **Clear color.** `PlayScene` never sets one; it inherits the startup scene's (0.08, 0.09, 0.12).
- **Shader tests:**
  - `WorldShaderContractTests` forbids `inverse(` in any `*vertex*.glsl` and requires exactly one `discard`, behind `WORLD_ALPHA_MASK`. It also regex-pins `Handle = program; _modelLocation = …; _normalMatrixLocation = …` in `Shader.cs`.
  - `Wave9AlphaMaskUniformCoverageTests` parses `uniform T name;`. A uniform block is invisible to that parse.
  - `WorldPassGlStateTests` pins this order: Clear, then blend off and depth on, then `.DrawWorld(`.
- **Persistence.**
  - An idle incremental checkpoint returns `null` and allocates nothing, so world time rides only on non-null checkpoints.
  - Every 12th checkpoint is full (about once a minute), and the shutdown checkpoint is full.
  - `world_metadata` is read only by `SqliteWorldMetadataRepository`.
  - `ServerBootstrap.CreateRuntimeHost` serves both the dedicated and the integrated server.
- **Dependencies.** Simulation may reference `Multiplayer.Protocol`, but not Server, Client or Rendering. `PlayScene.Render.cs` is already on the client allowlist.

## Strategy

The C0 contract files below are committed on the integration branch before any implementer starts, so every shared type exists and compiles in every branch.

Each C0 file has exactly one owner workstream. Only that owner edits it; for a stub, the owner replaces its body.

### Deviations from the roadmap

- **(a) No `server.world-clock` message in T1.** The debug override is client-local, and a reconnect re-anchors through join-accepted.
- **(b) Fog math lives in T1c's `lighting.glsl`.** T1d supplies the fog values, and T1e makes the sky's horizon match the fog.
- **(c) The view model gets its own range in the uniform buffer.** That range holds eye-space directions, the camera at the origin, and an ambient floor.

## Other Contracts

### `dream/shaders/lighting.glsl` (T1c)

It must match `FrameLighting` member for member:

```glsl
layout(std140) uniform FrameLighting {
    vec4 uSunDirection; vec4 uSunColor; vec4 uMoonDirection; vec4 uMoonColor;
    vec4 uAmbientSky; vec4 uAmbientGround; vec4 uFogColor; vec4 uCameraPosition; vec4 uLightingParams;
};
vec3 dreamAmbient(vec3 n) { return mix(uAmbientGround.rgb, uAmbientSky.rgb, n.y * 0.5 + 0.5); }
vec3 dreamDirect(vec3 n) {
    return max(dot(n, uSunDirection.xyz), 0.0) * uSunDirection.w * uSunColor.rgb
         + max(dot(n, uMoonDirection.xyz), 0.0) * uMoonDirection.w * uMoonColor.rgb;
}
vec3 dreamExpose(vec3 c) { return c * uLightingParams.x; }
vec3 dreamApplyFog(vec3 c, vec3 fragPos) {
    float d = max(distance(fragPos, uCameraPosition.xyz) - uCameraPosition.w, 0.0);
    float k = uFogColor.w * d;
    return mix(uFogColor.rgb, c, clamp(exp2(-k * k), 0.0, 1.0));
}
```

- **Cube shader:** `dreamApplyFog(dreamExpose((dreamAmbient(n) + dreamDirect(n)) * base.rgb), fragPos)`.
- **Enemy shader:** `lit = (dreamAmbient(n)*3.25 + dreamDirect(n)*0.75) * base.rgb; lit = max(lit, base.rgb * uLightingParams.y);`, then exposure, then fog. The constants are named `const float`s.

### Include mechanism (T1c, `Shader.cs`)

- `public static string ResolveIncludes(string source, string directory)` replaces each line `#include "file.glsl"` with that file's text. The file comes from the shader's own directory.
- One level only. A nested `#include`, a `#version` inside an included file, or a missing file throws.
- It runs at load time for both stages, before `InsertDefine`.
- After link, and after the pinned `_modelLocation`/`_normalMatrixLocation` lines, it calls `GL.GetUniformBlockIndex(program, FrameLighting.BlockName)`. If the index is >= 0, it calls `GL.UniformBlockBinding(program, block, FrameLighting.BindingPoint)`.

### Uniform buffer (T1c, `Rendering/Lighting/FrameLightingBuffer.cs`)

- One buffer with two ranges:
  - the world range, at offset 0;
  - the view-model range, at stride `RoundUp(144, GL UniformBufferOffsetAlignment)`.
- It is uploaded once per frame at the top of `WorldRenderer.DrawWorld(WorldSessionPresentationState)`:
  - **World range:** `CameraPosition.xyz` is the camera position.
  - **View-model range:** sun and moon directions are rotated by `mat3(view)`, `CameraPosition` is 0 (the fog start is kept), and ambient is `max(ambient, ViewModelAmbientFloor = 0.08)`.
- Uploads use `GL.BufferSubData(…, ref struct)`, so there are 0 allocations.
- `ViewModelRenderer.Draw` binds the view-model range, then restores the world range.

### Frame order (T1e, `PlayScene.Render`)

1. Evaluate the sky. Call `SetFrameLighting`, then `GL.ClearColor(horizon)`, then Clear.
2. Blend off and depth on (the existing test).
3. Draw the world (which uploads the uniform buffer), then enemies, the local player and remote players.
4. **Sky pass:** one full-screen triangle at depth 1, with `DepthFunc Lequal`, depth writes off, blend off and cull off. Restore `Less` and depth writes afterwards.
5. Debug collision, then the view model (on its own range), then the HUD.

The sky pass stays inside the "Actors" GPU timer section.

### Debug hook (T1e)

- `Rendering/Sky/TimeOfDayOverride.cs` is a `sealed class` with `bool Enabled`, `float TimeOfDay01` and `float Resolve(float replicated)`.
- It is exposed as `Render.TimeOfDayOverride` from a new `Render.Sky.cs` partial.
- In the Settings window (`Render.HudPanels.cs`), a collapsed "Time Of Day (debug, this client only)" header holds an Override checkbox and a 0–24 h slider.
- It never sends anything to the server.

## Workstreams

No file appears in two workstreams. Only the owner edits a C0 file.

### T1a: `WorldClock` and persistence

**Owns:**
- `WorldClock.cs` (the body) and `WorldClockSettings.cs`.
- A new `Simulation/World/WorldDayPhase.cs`: `enum WorldDayPhase : byte { Night, Dawn, Day, Dusk }`, plus a static `WorldDayPhases.At(double timeOfDay01)`.
- `WorldSessionRuntime.Clock.cs`. It adds `ConfigureWorldClock(WorldClockSettings, long worldTicks)`.
- `WorldSessionRuntime.Tick.cs`: one `WorldClock.Advance()` right after `CurrentServerTick = serverTick;` in `AdvanceAuthoritativeTick`, and never in `ProcessQueuedAuthoritativeActions`.
- `IRuntimePersistenceHost.cs`: `long WorldTicks => 0;` as a default member.
- `RuntimePersistenceBridge.Checkpoints.cs`.
- `PersistenceCheckpoint.cs`: `public long? WorldTimeTicks { get; init; }`, with `Merge` keeping `newer ?? older`.
- `SqlitePersistenceCheckpointWriter.cs`: upserts `world_time_ticks` in the same transaction when the value is non-null.
- `SqliteWorldMetadataRepository.cs`: `WorldTimeTicksKey = "world_time_ticks"` and `TryGetWorldTimeTicks`.
- `ServerPersistenceBundle.cs`: `long WorldTimeTicks`.
- `ServerBootstrap.cs`:
  - `DayLengthEnvironmentVariable = "DREAM_DAY_LENGTH_MINUTES"`.
  - `ResolveDayLengthMinutes(string?, Action<string>?)`: default 30, clamped to 1–1440; invalid input is logged and falls back to the default.
  - `CreateRuntimeHost` calls `host.Runtime.ConfigureWorldClock(settings, bundle?.WorldTimeTicks ?? 0)` before the first tick.
- `docs/configuration.md`: rows for `DREAM_DAY_LENGTH_MINUTES` and for T1d's `DREAM_NIGHT_BRIGHTNESS` (default 0.15, range 0–1).
- `docs/server-persistence-ddl.md`.

**API:**
- `Advance()`, `long DayNumber`, `double TimeOfDay01` (computed as `(W+S)%T / (double)T`), `WorldDayPhase Phase`.
- `event Action<WorldDayPhase, WorldDayPhase>? PhaseChanged`.
- Phase bounds:
  - Night: [20:00, 04:00). That is 10 minutes at the default day length.
  - Dawn: [04:00, 07:00).
  - Day: [07:00, 17:00).
  - Dusk: [17:00, 20:00).

**Must not touch:** `RuntimeAuthoritativeSessionHost.cs`, Protocol, Client, Rendering.

**Tests:**
- Defaults: 115,200 and 38,400 ticks.
- A new world reads 08:00.
- Advance and day rollover.
- Phase bounds, with one event per boundary.
- `Advance` allocates 0 B.
- `WorldTicks - CurrentServerTick` stays constant across ticks, and the runtime tick allocation tests still pass.
- SQLite restart continuity: run N ticks, dispose, reopen, and `WorldTicks == N`. A delay before reopening changes nothing.
- An idle incremental checkpoint is still `null`.
- `Merge`.
- Parsing of the environment variable.
- Determinism: two runtimes with different clock states and the same inputs give identical `SimulationStateChecksum` and `WorldStateChecksum`, and the physics goldens are unchanged.

**Accepted when:** time survives a clean restart, and a crash loses at most about 60 s of world time.

### T1d: `SkyModel` (pure)

**Owns:** `SkyState.cs`, `SkyModelSettings.cs`, `SkyModel.cs` (the body), and new `Rendering/Sky/SkyModel*.cs` helpers.

**Sun path:** a great circle through the east and west horizon points that passes exactly through `ReferenceNoon.SunDirection` at 12:00. Sunrise is at 06:00 and sunset at 18:00. The moon is `-sun`.

**Keyframes:** night, dawn, noon and dusk, interpolated smoothly and wrapped.

**Required values:**
- At 12:00, sun, ambient and params equal `ReferenceNoon`.
- At night:
  - sun intensity is 0;
  - the moon is cool (b > r);
  - up-facing ambient plus moon light is about `NightBrightness` × noon's up-facing value (0.2 + 0.4286);
  - the actor floor and exposure are scaled to suit.
- `HorizonColor == FogColor.rgb` at all times.
- Fog reaches at least 0.9 at 48 units and at most 0.1 at 16 units, at all times.

**Must not touch:** anything else.

**Tests (new `SkyModelTests`):**
- The required values above.
- Continuity over 10k samples, including across the wrap.
- `Evaluate(t) == Evaluate(t ± 1)`.
- Directions are unit length.
- Stars are 1 at midnight and 0 at noon.
- `Parse`.
- `Evaluate` allocates 0 B.

## Determinism And Budgets

- Only T1a touches the simulation. The clock reads only ticks. It is kept out of both checksums, and a test pins that.
- T1b changes only the join bytes. The snapshot goldens and the snapshot byte sizes are unchanged.
- An idle checkpoint stays allocation-free.
- The sky costs about one more draw per frame.

## Merge Order And Glue

The merge order is C0, then T1a, T1b, T1c, T1d, T1e. Build and test after each merge. No conflicts are expected.

3. Run the perf harness.
4. Take screenshots at 08:00, 12:00, 18:00 and 00:00 using the debug slider.
