## A. Boundary mist wall
(a) Per-fragment smoke: new include shaders/boundaryMist.glsl, included right after lighting.glsl in cubeFragment, enemyFragment, fxFragment. Every surface mixes toward smoke by opacity from its own world XZ (exact, no depth read, hides terrain side faces, actors/props past the edge).
- cube/enemy: `FragColor = vec4(dreamApplyBoundaryMist(dreamApplyFog(<as now>, fragPos), fragPos), <alpha as now>);`
- fx: `... * dreamFogTransmittance(vWorldPos) * (1.0 - dreamBoundaryOpacity(vWorldPos));`
- Noise only where opacity > 0 (dynamic branch).
(b) Void pass: BoundaryMistVoidRenderer (SkyRenderer pattern), fullscreen triangle at depth 1, DepthFunc Lequal, depth writes off, premultiplied blend, reuses skyVertex.glsl unchanged. Ray = uniform uEye (true camera pos) + dir from vFarPoint, intersect plane y=floorTop: hit outside map -> opaque dreamBoundarySmoke(hit), alpha 1; inside (dug hole) or upward -> alpha 0. Runs in all camera modes right after the sky branch. Smoke samples the point projected onto the floor plane along uMistView so world fragments at opacity 1 and void pixels share one noise field (no seam).
Opacity: d = signed inset min(x-minX, maxX-x, z-minZ, maxZ-z) (+ inside). d' = d + NoiseAmp*(2n-1)*clamp(d/0.5,0,1), NoiseAmp 0.35. b(d) = pow(clamp(1 - d'/RampStart,0,1), Gamma), RampStart 3.5, Gamma 3. b(0)=1, b(0.5)~0.63, b(1.5)~0.19, b(>=3.85)=0. At d<=0 always 1.
Look: 2-octave value noise on (x,z) advected at 0.25 m/s + rising term (one octave on time*0.4); brighter churn 0-2 m outside the edge, darker deeper. Albedo mix((0.11,0.11,0.13),(0.38,0.38,0.42),noise), lit as up-facing: `albedo*(dreamAmbient(up)+0.6*dreamDirect(up))*uLightingParams.x`. No point lights. No exp2(/distance( calls; hash-based noise.
UBO BoundaryMist binding 2, std140, 48 B, mirrored by BoundaryMistFrame, world + view-model ranges like LightListBuffer (view-model strength 0):
```glsl
layout(std140) uniform BoundaryMist {
    vec4 uMistBounds; // minX(0) minZ(0) maxX(Width) maxZ(Depth)
    vec4 uMistParams; // strength (1 on, 0 off/view model), time s (wrap 600), floorTopY (1), RampStart (3.5)
    vec4 uMistView;   // xyz unit camera front, w 0
};
```
Shader.cs: BoundaryMistBuffer.BindProgramBlock(program) after the other two. Render.UploadFrameLighting uploads once/frame; BindWorldLighting/BindViewModelLighting bind ranges (Render.Lighting.cs). Scene sets `Render.BoundaryMist = new BoundaryMistInput(width, depth, timeSeconds, enabled)` each frame before DrawWorld.
BoundaryMistField (pure C#): constants + CPU Opacity(d,n); `StopInset => Player.EdgeMargin`; tests tie clamp to curve. Clamp unchanged (no protocol/persistence/server change). WorldCursorPicker edge tests: picks 5 m and 40 m past each edge and corner -> edge cell whose centre is the clamp line; upward ray -> None; change code only for a real gap.
Settings: DREAM_BOUNDARY_MIST=0|1 (default 1) in BoundaryMistSettings.FromEnvironment(); visual only; no user toggle.

## B. War mist: stacked horizontal slices
WarMistRenderer: one DrawArraysInstanced, 4-vertex strip from gl_VertexID x N instances, no VBO (FxRenderer pattern). Instance quads at y = 1 + {0.10,0.60,1.20,1.90,2.70,3.60} (N=6, bottom first). XZ extent focus+-26 m clipped to [0,W]x[0,D]. State: depth test Less, depth writes off, blend (One, OneMinusSrcAlpha), cull off; restore blend off and depth mask true.
Density: dist = XZ distance from focus. vis = 1 - smoothstep(ClearRadius 6.5, FullRadius 12, dist); target = (1-vis)*mix(Unexplored 0.72, Explored 0.30, explored01)*noiseMod (noiseMod in [0.6,1.3]); per slice alpha = 1 - pow(1 - clamp(target,0,0.95), 1/N) times per-slice noise variation. Inside ClearRadius exactly 0.
Noise: tileable 128^2 RG8 fbm texture generated in C# at creation with a fixed seed (WarMistNoiseTexture); two fetches/fragment. Wind dir (0.8,0.6), 0.35 m/s, per-slice phase, 1.3x speed difference between layers.
Colour: albedo (0.30,0.31,0.34), lit like boundary smoke; shader includes lighting.glsl read-only; premultiplied output scaled by dreamFogTransmittance(worldPos).
ExplorationMemory (pure C#): byte[W*D]. Reveal(x,z) when player moved >= 0.5 m since last reveal: max(old, 255*(1 - smoothstep(8,10,d))) within 10 m, dirty flag. Reset(w,d) on map instance/size change. ExplorationTexture: R8 WxD, linear, clamp, full TexSubImage re-upload only when dirty. No per-frame allocation. Memory only, not persisted/sent.
Scope: iso only (off in first/third person). Visual only.
Settings: DREAM_WAR_MIST=0|1 (default 1); DREAM_WAR_MIST_EXPLORED=none|all (default none; all reveals map at start for capture); DREAM_WAR_MIST_SLICES 2..8 (default 6). GameSettings.WarMistEnabled runtime bool (default from env) + "War Mist" checkbox in Settings ImGui window (Render.HudPanels.cs); not persisted.
Pass: `DrawWarMistPass(in presentation, deltaSeconds)` is the FIRST statement of DrawEffectsPass, before its early-return guard. Timed in the Actors GPU section. Renderer created lazily on first draw on the render thread; failure -> one `war-mist` line in RenderFaultLog and mist disabled. Disposed from DisposeEffects() via DisposeWarMist().
