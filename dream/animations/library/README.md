# Asset Library

This folder holds legally reusable source packs that are copied into the build output with the rest of `dream/animations/**`.

## Current Sources

- `kenney/`: CC0 packs from Kenney, including `nature-kit` and `animated-characters-retro`
- `quaternius/`: CC0 packs from Quaternius, including animals and character variants
- `polyhaven/`: CC0 terrain textures from Poly Haven

## Usage Notes

- Treat these assets as the curated source vault for future environment, creature, and player-content work.
- Keep source-pack structure intact when possible so license files and pack metadata stay adjacent to the art.
- Add new imported assets here first, then reference them from gameplay or rendering code once they are approved for use.
