# Asset Library

This folder holds legally reusable source packs that are copied into the build output with the rest of `dream/animations/**`.

## Current Sources

- `kenney/`: CC0 packs from Kenney, currently `animated-characters-retro`, `food-kit`, and `nature-kit`
- `quaternius/`: CC0 packs from Quaternius, currently `animals`, `characters`, `fantasy-props-megakit`, `stylized-nature-megakit`, and `survival-pack`
- `polyhaven/`: CC0 terrain textures from Poly Haven
- `skyboxes/`: CC0 sky texture packs, currently OpenGameArt `cloudy-skyboxes` in both cubemap and panorama variants

## Usage Notes

- Treat these assets as the curated source vault for future environment, creature, and player-content work.
- `food-kit`, `fantasy-props-megakit`, `stylized-nature-megakit`, `survival-pack`, and `cloudy-skyboxes` now give the repo a ready-made source pool for foliage, rocks, tools, weapons, market props, household items, food, fruit pickups, and day/night sky backgrounds.
- Keep source-pack structure intact when possible so license files and pack metadata stay adjacent to the art.
- Add new imported assets here first, then reference them from gameplay or rendering code once they are approved for use.
